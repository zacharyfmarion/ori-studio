# oristudio/cp-detect-exact-solve-comparison/v1

Generated by `compare_exact_solve_benchmark`.

This directory compares frozen legacy decode, Stage 5 selected graph, and Stage 6 exact-solved graph from the same dense cache.

Files:

- `summary.json`: aggregate machine-readable metrics.
- `summary.md`: human-readable aggregate table.
- `per_sample.jsonl`: one full metrics record per sample.
- `regressions.jsonl`: metric regressions detected by the benchmark.
